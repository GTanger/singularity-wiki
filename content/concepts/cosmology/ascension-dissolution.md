# 飛升即消融——修煉物理的終極真相

> 2026-04-12 設計者親述，定案級世界觀

## 修煉三態

| 路徑 | 過程 | 結果 |
|------|------|------|
| 不碰 Token | 安全生活 | 平凡 |
| 止念 + 功法 | 有序轉化游離輻射為己用 | 變強，但接近消融線 |
| 直接汲取輻射（無功法） | 混沌直接衝擊身體 | 爆體或飛升 |

## 飛升的真相

飛升不是超越。是**消融**。

全身與 [[Token]]（創造者的念場）同頻 → 創造者不再識別你為「人」→ 不再 [[禮讓|Token的禮讓]] → 被背景輻射吸收 → 你不再是你。

**爆體和飛升是同一件事的兩種表現：**
- 爆體 = 混沌撕裂了你的秩序（身體承受不了）
- 飛升 = 混沌取代了你的秩序（你變成了 Token）

## 修煉天花板

天花板不是力量上限，是**你還能是你的極限**。

越強 → 越接近 Token 的頻率 → 越容易被同化。最強的修煉者是離消融最近的人。

## 止念的本質

止念 = 暫時讓自己不像「人」→ 創造者不再禮讓 → Token 輻射照常運作 → 透過功法將混沌輻射有序轉化入體。

**止念是短暫放棄被當成人的權利，換取接觸創造者之念的機會。**

## 與 NPC 品質的關係

創造者的禮讓 = 萬物存在的前提。NPC 的獨特性（異步、差異性、萬人萬相）= 創造者禮讓的證據。NPC 越像真人，創造者就退得越遠。像機器人的 NPC = 創造者沒有真的退開。
