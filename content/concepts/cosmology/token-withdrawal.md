# Token 密度與聚念場——物理機制

> 2026-04-12 設計定案級世界觀　｜　2026-04-13 修訂：移除擬人化措辭

## 核心機制

Token 游離輻射充滿宇宙每個角落，無處不在，無時不息。Token 本身什麼也沒做——它只是存在。

高頻有念生物（泛指類人種，大腦發達者）的意識頻率與 Token 游離輻射產生**同頻相斥**效應，使得有念生物身邊的 Token 密度被壓低。這是物理現象，不是任何一方的主動選擇。

- Token 密度在有念生物周圍下降 = 同頻相斥的自然結果
- 有念生物離開 → Token 密度**瞬間**恢復 1.0（輻射無限，永遠回滿，無延遲）
- 造成[[富態化]]的不是 Token，Token 什麼也沒做。造成富態化的僅僅是游離輻射的副作用

## 聚念場

[[聚念場]]是高頻有念生物聚集時，同頻相斥效應的疊加。人越多，場越強，局部 Token 密度越低。

聚念場不是力場，不是防護罩，不是某種主動施展的屏障——是多個有念生物的存在效應自然疊加的結果。

## 止念的物理解釋

[[止念]] = 有念生物主動壓制自身意識頻率至趨近於零。

頻率壓低 → 同頻相斥消失 → 物理上不再被視為「高頻有念」→ Token 密度在身邊恢復 → 游離輻射可被汲取。

止念的本質：暫時放棄作為高頻有念生物的物理特徵。在止念狀態下，修煉者與無念之物無異——這是能汲取 Token 輻射的前提條件。

## 獨居不可能

單一有念生物的同頻相斥效應只能壓住身邊極小範圍。睡覺時意識頻率下降，效果更弱。離家時家中瞬間 1.0。

再強大的個體也改變不了這個事實——問題是物理，不是敵人。世界從底層物理把人往一起推。

## 與其他概念的關係

- [[富態化]]：Token 游離輻射對萬物的副作用，Token 本身無意為之
- [[聚念場悖論]]：人多 → 密度低 → 資源長得慢；人少 → 密度高 → 資源豐但危險
- [[飛升與消融]]：修煉越深，意識頻率越接近與 Token 同化的臨界點
- [[降維歸屬權]]：有序化後的能量不再具有 Token 混沌性質，屬於降維者
