# DeepSeek V4 觀望

**日期：** 2026-04-10

## 狀態

尚未正式發布。所有 benchmark（HumanEval 90%、SWE-bench 80%+、MATH 92%）為洩漏內部數據，無第三方驗證。

## 關注原因

## 評估計畫

等 API 正式開放＋LMSYS 盲測結果出來再評估。可拿同一張工單讓它跑一輪，與 Flash 三修對比。
