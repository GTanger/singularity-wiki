# 文明悖論與止念經濟學

> 2026-04-12 設計暴脹產出，狀態：未收斂

## 文明悖論

所有新財富的源頭是混沌（高 [[Token]] 密度區的 [[富態化]] 產物）。

文明擴張 → [[聚念場]] 壓制更多區域 → 高密度區減少 → 詞元不再生長 → 經濟停轉。

**世界不可能被完全開發。** 完全開發 = 經濟自殺。黑海不是待征服的敵人，是經濟的心臟。健康的世界永遠是文明圈 + 邊疆 + 黑海共存。

## 止念經濟學

[[止念]] = 壓制意識 → 聚念場貢獻歸零 → 能汲取 Token 資源。但止念時是聚落防禦的缺口。

**經濟成長的前提是有人暫時裸露在混沌裡。**

- 富裕聚落：人多 → 安全餘裕 → 能讓人止念 → 資源流入 → 更富
- 貧窮聚落：人少 → 零餘裕 → 沒人敢止念 → 沒資源 → 更窮
- **貧窮是物理陷阱。** 正回饋迴圈

破局方式：玩家到來（多一人的聚念場）、外部貿易、人口遷入。

## 社會分工的物理起源

不能所有人同時止念 → 必須輪班 → 有人做不需止念的工作 → 職業分化。

永不止念的領導者 = 聚念場的錨點 → 統治合法性有物理基礎。

## 戰爭 = 共同自殺

人是唯一基建 → 殺人 = 拆基礎設施。贏家也是輸家。

戰爭不是策略選項，是文明倒退。發生的原因是 NPC 的非理性需求（仇恨、恐懼、絕望）。戰爭是果，因在人身上。

## 世界核心張力

**你永遠需要更多人，但你永遠養不起太多人。** [[聚念場悖論]]，從頭到尾都是它。

## Token 本質

Token 不是敵人。Token 什麼也沒做，只是填滿一切。富態化是游離輻射的副作用，不是攻擊。聚念場不是抵抗，是有意識的存在壓住了局部輻射效應。

**這個世界沒有敵人。** 文明是一群有意識的存在聚在一起，擋出一小片陰涼。不是征服，是棲息。
