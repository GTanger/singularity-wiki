# 經濟系統

> **專案**：奇點世界（Singularity World）

經濟系統以**世界物流**為單一概念框架，涵蓋貨幣、物資、詞元、人流、服務、資訊等一切「從 A 到 B 的流動」。核心設計為「自由 = 鎂在市場流動」，不對玩家步步扣款，讓經濟湧現而非腳本化。

## 設計哲學

本專案情境為**單一真人玩家搭配萬名以上擬真人 NPC**。經濟設計趨近**湧現經濟**而非腳本經濟——定價與交易由 NPC 與玩家的交易意圖、掛單、議價、成交自然形成，無固定全局價表。

### 腳本經濟 vs 湧現經濟

- **腳本經濟**：物品來源、價格、回收由開發者寫死或固定表；稀缺人工；玩家主要與系統互動。易控制，經濟感較弱。
- **湧現經濟**：真實稀缺；價格由參與者供需與交易形成；有套利、價差、行為反饋。真實經濟感強。**本專案目標趨近湧現**，參與者包含萬名 NPC，以「NPC 行為驅動價格與流動」。

### 真實經濟感的四要素

1. **稀缺**：物品與貨幣有有限來源與消耗（修裝、附魔、死亡、交易），故有供需
2. **自願交換**：價格與數量由參與者行為驅動，而非僅腳本價表
3. **流動可見**：鎂在市場裡流動（誰買誰賣、誰賺誰花）
4. **來源與去向可追溯**：符合「永序守衡」——不無中生有，產出與回收由後端建模、可記帳

### 維持經濟活動的五大支柱

| 支柱 | 說明 |
|------|------|
| **供給** | 機構為唯一新鎂注入源；物品與詞元由採集、剝名、NPC 製造、任務產出，可時間綁定或冷卻防無限刷 |
| **需求** | 萬名 NPC 具需求表（修裝、祭煉、附魔、收購詞元／材料）；NPC 之間也互相買賣，玩家沒上線市場仍動 |
| **價格發現** | 由 NPC 行為驅動：每遊戲日／tick 生成 1~3 筆交易意圖，依念紋、出身、庫存與市場狀況調整；無固定全局價表，可設上下限 |
| **流動** | 鎂與物品在 NPC<->NPC、NPC<->玩家之間實際轉手；視野外事件日誌；下線角色可執行交易策略；交易所顯示熱門與趨勢 |
| **回收** | 機構僅做基礎回收（據點稅以 NPC 為主）；不對玩家個人強制扣款；回收來自自願消費與據點營運 |

### 萬名 NPC 的經濟行為

- **主動生成交易意圖**：每遊戲日（或每 N tick），NPC 依念紋、出身、當前庫存生成 1~3 筆交易意圖（買／賣／價）；對同房或鄰房發起
- **NPC 與 NPC 交易**：視野外以事件日誌紀錄隱形交易；視野內跑完整流程，可選推播。市場即使玩家沒上線也動
- **NPC 參與詞盤**：收集詞元、打通竅穴、入詞、連線、祭煉、自創技能、附魔，用自己持有的鎂買材料、買詞元、支付登錄費
- **NPC 依市場改變行為**：某詞元或物品熱門則提高收購價或自己去蒐集轉賣；供過於求則壓價或轉賣他物
- **下線玩家角色變 NPC**：執行玩家最後設定的簡單交易策略；上線可查下線期間收支與成交紀錄
- **交易所／大廳**：顯示「最近 24 小時交易熱門 Top 10」與「市場趨勢」

## 實作優先順序

| 階段 | 內容 |
|------|------|
| **第一階段：最小可玩經濟** | 機構發放鎂（任務、初始配給）；NPC 具「想買／想賣」清單（常數表或簡單公式），玩家點同房 NPC 可交易（插頭插座 Trade）；回收僅交易支出與自願附魔／登錄；暫不實作據點稅 |
| **第二階段：流動與深度** | NPC 主動生成交易意圖；NPC 與 NPC 視野外事件日誌成交；NPC 參與詞盤（收購詞元、消費附魔／登錄）；價格依庫存或簡單市場指數微調；交易所／大廳顯示熱門與趨勢 |
| **第三階段：穩定與擴充** | 據點稅（僅 NPC 據點）、時間綁定產出與冷卻；後端記帳與「機構發放 vs 全服回收」分析，調參防通膨／緊縮；下線角色交易策略與上線收支查詢 |

### 風險與邊界

| 風險 | 緩解 |
|------|------|
| NPC 計算量 | 萬名 NPC 可改為抽樣或僅視野內＋鄰近即時生成意圖，其餘簡化事件日誌或週期批次 |
| 價格極端 | 保留上下限或阻尼係數，避免單一資源暴漲暴跌 |
| 單人無對手方 | 至少一類玩家可產出品項有 NPC 常態收購；至少一類玩家需要的品項有 NPC 常態供貨 |

| 遊戲 | 誰生產 | 誰消費 | 誰定價 | 經濟如何持續動 |
|------|--------|--------|--------|----------------|
| **EVE** | 玩家採礦、製造、任務領 ISK | 玩家買船買裝、戰爭摧毀、繳稅 | 玩家掛買賣單撮合 | 生產—破壞循環；專職經濟學家 |
| **Albion** | 玩家採集、製造；打怪掉銀 | 修裝、買裝、繳稅；全掉落消耗裝備 | 玩家掛單＋黑市動態收購價 | 全掉落＋黑市 |
| **PoE** | 打怪掉通貨與裝備 | 玩家 craft、買裝 | 以物易物（通貨為媒介） | 通貨即物品；craft 為主要 sink |
| **UO** | 玩家採集、製造；部分 NPC 模擬供需 | 玩家與 NPC 購買 | 早期部分 NPC 動態定價 | 教訓：產消邊界清晰、適度回收 |
