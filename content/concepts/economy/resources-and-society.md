# 資源與社會

> 資源點、Token 密度模型、農業、採集管線、材料分類、資源節點實作。與[[currency-and-flow|鎂貨幣]]及[[trade-and-logistics|交易與世界物流]]交叉參照。

## 聚念場悖論（世界通用定理）

此定理適用於所有資源點，為**世界觀的物理定律**而非遊戲規則：

- **人少** -> 聚念場弱 -> 富態化旺盛 -> 資源豐富但環境危險
- **人多** -> 聚念場強 -> 富態化被抑制 -> 資源生長變慢
- 因此所有採集活動存在**最佳人數平衡點**

### 經濟意涵

- **公會壟斷物理上不可能**——派人站崗 = 人在場 = 密度低 = 資源永遠長不回來。這不是規則限制，是世界觀的物理定律
- **最優策略 = 脈衝式採集**：組隊快速挖光 -> 全部撤離 -> 等回滿 -> 再來一波。天然鼓勵社交協作但反對霸佔
- 礦業永遠有活幹，支撐經濟循環不崩盤
- NPC 行為循環：組隊 -> 快速開採 -> 撤離 -> 等待 -> 再來

## Token 密度模型 `定案`

Token 游離輻射源源不絕、不會被消耗。影響資源生長的是當前位置的 Token 密度，行為類似流體。

### 流體位移模型

有念生物進入場域（hex 格）產生兩層效應：

1. **體積位移**：有念生物的身體直接擠開等體積的 Token 輻射，如同人進入泳池擠開等體積的水。人離開的瞬間，Token 立即回填——**沒有冷卻時間**，密度恢復是即時的
2. **念場相斥**：有念生物持續散發高頻有念游離輻射，與周圍空間的 Token 輻射相斥，進一步壓低場域內的 Token 濃度。以人為中心向外擴散的場效應

兩者疊加決定場域的實際 Token 密度。

### 密度表

| 狀態 | Token 密度 | 資源表現 |
|------|-----------|---------|
| 無人 | 1.0（滿） | 正常富態化生長 |
| 1 人 | ~0.9 | 生長略慢，一人敲 10 下掉落 |
| 3 人 | ~0.7 | 生長更慢，但每人只敲 3 下 |
| 大隊駐守 | -> 0 | 生長趨零 |
| 人離開 | 瞬間回 1.0 | Token 立即回填 |

### Hex 格 = 場域

一個 hex 格不是座標點，而是一片場域。密度計算的是整個場域的整體濃度。資源體佔據場域空間，採集者進入場域後對資源體進行作業——不存在「腳下撿東西」的概念。

### 代碼層面公式

```
Token 密度 = 1.0 - f(在場有念生物數量)    // 下限 0（實作規範中暫定下限 0.1）
資源再生速率 = renew_base * Token 密度
採集速度 = 基礎敲擊數 / 在場人數          // 協作加成
冷卻機制 = 不存在。人在不在場就是冷卻
```

## 資源個體與成熟度 `定案`

### 完全變態質

每個資源個體有成熟度 **0.0 -> 1.0**。即便富態化，上限仍為 1.0——富態化加速的是 0->1 的過程，不改變天花板。**成熟度到 1.0 才可採收**，未成熟不可採。

### 物件制（沿用 MUD 設計）

資源場域（hex 格）內的每個資源個體是獨立的可互動物件：

- 成熟度到 1.0 -> 物件出現在場域中（玩家可看到、可互動）
- 採收 -> 物件消失，該位開始重新從 0 生長
- 場域有容量上限（`capacity`），決定同時能孕育多少個體

房間描述不需要動態化。**變的是房間裡有什麼物件**，不是房間本身的文字。

### 兩層結構

- **hex 級**：Token 密度（由在場有念生物數決定），影響場域內**所有**個體的成長速率
- **物件級**：各自的成熟進度 0->1，成長速率 = `base_growth * hex_density`

密度是全場域共享的。人多了，場域內所有正在生長的個體一起變慢——不存在「這棵不受影響」的例外。

## 地下礦區

- 位於浮生城地下一層，透過地下電梯連接地面
- 因富態化影響，地層不斷擴增、擠壓，持續生成各種礦石
- 地層因富態化擴增的速度**大於**人類開採速度 -> 資源永不枯竭
- 這是人力開闢的極限範圍區域
- 合理解釋「為什麼資源挖不完」——不是刷新機制，是世界本身在生長

## 採集流程 `定案`

### 完整流程

1. 資源個體成熟（0->1）-> 物件出現在場域中
2. 玩家對物件下「採集」-> 後端依**插頭/插座語義**判定：物件插座定義接受的工具類型 vs 玩家 hold_l / hold_r 實際持物
3. **不符合 -> 拒絕**（如「需要鎬類工具」）。不存在「赤手但效率極低」的中間態——能做或不能做，由插座定義
4. 符合 -> 進入 **Gathering 狀態**（被動放置），系統自動結算
5. 每 tick：扣物件耐久、扣玩家體力
6. 物件耐久歸零 -> 物件消失、產物進背包、該位重新從 0 生長
7. **中斷條件**：體力歸零 / 移動 / 受攻擊 / 主動停止 / 背包滿

### 工具判定

赤手能不能採取決於**資源物件自身的插座定義**，不是全域規則：

- 草藥類：插座接受赤手（無持物要求）
- 礦脈類：插座要求鎬類工具，赤手不可採

對齊「裝備 = 工具」與「不可無中生有」原則——赤手敲碎礦脈違反物理常識。

### 採集時間因素（規格待定）

- **物件端**：hardness（物質硬度），決定基礎耐久
- **採集者端**：工具 tool_power、體質修正、工具熟練度（待定）
- **體力消耗**：每 tick 扣體力（四相之一），歸零強制中斷

## 採集 -> 材料 -> 剝名 -> 結晶 -> 提出管線 `定案`

| 階段 | 輸入 -> 輸出 | 決定什麼 | 門檻 |
|------|------------|---------|------|
| **採集** | 場域資源體 -> 材料 | 種類、數量、節奏 | 插頭/插座（工具匹配） |
| **剝名** | 材料 -> 詞元結晶 | 結晶品階（丙/乙/甲） | **無**（人類基礎能力） |
| **儲存/交易** | 結晶流通 | -- | 結晶可收納、可交易 |
| **提出/提煉** | 結晶 -> 裸詞元 | 提取成數（3~9 成） | 功法（人人會基礎） |
| **使用** | 裸詞元 -> 載體 | 入竅/附魔/疊煉/鑄鎂 | 即時，不可延遲 |

### 五層各司其職

- 材料 = 庫存層、剝名 = 轉換層、結晶 = 流通層、提出 = 品質層、裸詞元 = 消費層
- **三個決策點**：剝名時（單剝/合剝/投入什麼材料）-> 提出時（用什麼功法/現在提還是等更好的功法）-> 使用時（入竅/附魔/疊煉/鑄鎂）

### 剝名 `定案`

從材料中剝離 Token 烙印 -> 物質消散 -> 烙印失去載體後**自然凝結成結晶態**（如舍利子），即**詞元結晶**。

- **剝名是人類基礎能力**：不需要特定工具、場所、或技能等級。赤手可剝——剝名是念場對物質的作用，不是物理敲打
- **品階（丙/乙/甲）= 剝名時擲骰**

#### 剝名投入模式

- **單剝**（一材料一剝名）：結晶數量多，每個能量低，向量方向相對可預測
- **合剝**（數材料合一剝名）：結晶數量少（可能僅一個），投入的混沌能量總量大，多重烙印疊加後**向量方向不可預測**——賭注越大、結果越不可控

### 詞元結晶（可儲存態）

- **可收納**：放入背包、倉庫
- **可交易**：市場主要流通物
- **僅品階可測**（設計者定案）：結晶上可感知品階（丙／乙／甲），但**屬性方向不可知**——提出前不知道是什麼字
- 市場定價以「品階 + 產地」為錨（如「甲級山礦結晶」），產地暗示屬性方向但不保證（混沌本質）
- **壟斷結晶有意義，壟斷裸詞元不可能**——結晶可囤可交易，裸詞元必須即用

### 提出／提煉 `定案`

用功法從結晶中提取裸詞元。結晶崩解，裸詞元**不可收納、不可交易**，須立即灌入載體。

**兩層品質**：

- **品階（丙/乙/甲）** = 結晶本身的等級，剝名時決定
- **提取成數（3~9 成）** = 功法從結晶中提取多少潛力，提出時決定

甲級結晶 x 爛大街功法（3 成）可能不如乙級結晶 x 頂尖功法（9 成）。**品階 x 成數 = 最終詞元實際效力**。

**功法成數**（機構賦權定義）：

- 爛大街功法：3~5 成
- 國家級：穩定 7 成，極低機率 9 成
- 頂尖功法：高機率 7 成，且比國家更高機率 9 成

**國家代提**：國家機構可代為提出（穩定 7 成），收取市價三成為費用。「官方剝名處」實為**官方提出處**——剝名人人會不需要代工，值得代工的是提出品質。

**功法成為稀缺資源**——自然驅動門派、師徒、國家代提等社會結構。

## 材料分類 `定案`

材料**不設中間子分類**。只有五大來源類 + 產地節點 ID：

| 欄位 | 說明 |
|------|------|
| `source_class` | `mineral` / `beast` / `plant` / `water` / `gas`（五大來源類） |
| `source_node_id` | 來自哪個資源節點（攜帶地理、生態、詞元權重池等所有資訊） |
| `weight` | 物理重量（負重計算用） |

不設「鐵礦石」「銅礦石」「靈石」等中間種類——Token 烙印本質混沌，材料外觀不決定內容。玩家以「品階 + 產地」辨識材料價值。獸類材料 = 獸體/肢體本身，獸種即分類。

### 與詞元表的對接（剝名層）

- 材料本身**不**直接對應詞元 id。對接發生在**剝名時**：系統查 `source_node_id` 對應的詞元權重表（`stripping_weights`），從 500 詞元中按權重抽樣
- 產地決定權重偏向，但不鎖死結果（Token 烙印混沌本質）

## 資源節點資料結構

### PostgreSQL 架構（權威來源） `定案`

```sql
CREATE TABLE resource_pools (
    id SERIAL PRIMARY KEY,
    key VARCHAR(50) UNIQUE NOT NULL,
    kind VARCHAR(20) NOT NULL,       -- mine, wild_gather, water, farm
    entries JSONB NOT NULL           -- [{item_id, weight}, ...]
);

CREATE TABLE resource_nodes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    hex_q INTEGER NOT NULL,
    hex_r INTEGER NOT NULL,
    pool_id INTEGER REFERENCES resource_pools(id),
    danger_level REAL DEFAULT 0.0,
    renew_base REAL DEFAULT 1.0,
    active BOOLEAN DEFAULT TRUE,
    UNIQUE(hex_q, hex_r)             -- 一格一節點
);
```

### 節點類型與產出方向

| kind | 敘事定位 | 危險度 | 產出方向 |
|------|----------|--------|---------|
| `mine` | 地下／露天礦脈，脈衝採集 | 中~高 | 偏礦／石／金屬材 |
| `wild_gather` | 野外富態化植株／殘骸 | 高 | 偏植／獸材 |
| `water` | 水域（待世界觀細化） | 中 | 偏水／流／寒等材 |
| `farm` | 聚念場邊緣（P2） | 低 | 低波動、高穩定產出 |
| `special` | 劇情／遺跡／一次性 | 依劇情 | 手工配置池 |

### 空間錨點原則

1. 權威座標以 Hex 為準（`cell_id` 或 `q,r`）
2. 一點一錨：每個資源點一個穩定 id
3. 語意分層：區域級決定「允許哪些類型節點」，節點級決定「具體產出池、危險係數」

### 設計者定案（2026-04）

**捨棄「所有礦點都能出產所有礦物」（all-in-one）**——礦種與掉落由區域規則 + 節點 `yield_pool` 分區配置。富態化不是用來合理化「同一節點無條件萬能產出」的作弊鍵。

## 農業系統 `概念定案，P2`

| 環境 | 作物表現 | 混沌能量 |
|------|---------|---------|
| 聚念場邊緣（城市農田） | 富態化受抑制，個體偏小（稻米約半身高） | 低（5~10 單位/顆） |
| 野外（無聚念場） | Token 全力輻射，稻米 -> 靈米樹（超人身高） | 高（~100 單位/顆） |

- **自種 = 低價值但安全穩定**，符合城市生活低風險低回報
- **野採 = 高價值但危險**，三面向選擇壓力（剝詞入體 / 售鎂 / 附魔）
- 農業與聚念場悖論天然對齊，不需額外設定
- 野外靈米樹 -> 食草獸食糧 -> 食肉獸食糧 -> 完整食物鏈

## 社會組織層次

社會組織是資源控制的具現化。四個層次依規模遞增：

| 層次 | 名稱 | 規模 | 資源控制方式 |
|------|------|------|-------------|
| **氏族（Tribe）** | 血緣/地緣小組 | 10–50 人 | 控制單一資源節點；自給自足 |
| **公會（Guild）** | 職業聯盟 | 50–500 人 | 控制同類資源的多個節點；交換與壟斷 |
| **城市（City）** | 政治實體 | 500–5000 人 | 控制整個 region 的資源分配；課稅 |
| **國家（Nation）** | 最高機構 | 5000+ 人 | 功法賦權（提出品質）；貨幣發行（鎂）|

### 關鍵設計原則

- **物理壟斷不可能**（聚念場悖論）：人多 → 密度低 → 資源長得慢；強行壟斷會讓自己挖不到東西
- **脈衝式採集才是最優解**：來一波挖完走人等回滿，比長期佔據更有效
- **國家級機構的核心價值**：不是土地控制，是功法品質（代提 7 成以上）和鎂的發行權

### 技能（戰鬥能力組合模組）

技能不是獨立的「絕招 ID」，而是由詞盤造句公式 + 戰鬥結算參數組合而成的**功能模組**。

| 技能來源 | 描述 |
|---------|------|
| 詞元向量合成 | 玩家選字 → 向量相加 → 技能效果（連續光譜） |
| 竅穴頻率 | 入竅詞元永久改變施法頻率特性 |
| 裝備附魔 | 裝備上的詞元半永久強化輸出型態 |

詳見 [[wordplate-system/skills-and-equipment|技能與裝備系統]]。
