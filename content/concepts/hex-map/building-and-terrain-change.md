# 建造與地格性質改變

> 2026-04-12 設計暴脹產出，狀態：未收斂

## 核心概念

建造 = 改變地格性質。玩家和 NPC 都能建造（同構同驅同感）。

建造在地格上疊加人造物或改變地格本質：
- 荒野 → 農田（生態重定義）
- 森林 → 空地（原生態移除）
- 河岸 → 橋（連通性改變）
- 空地 → 建築 → 累積成聚落

## 建造與 Token 物理

**建築不壓制 Token。人才壓制 Token。**

- 建築是死物，沒有念，不產生 [[聚念場]]
- 建造者離開的瞬間，該格 Token 密度回到 1.0，[[富態化]] 全開
- 沒人住的建築會被富態化快速接管
- 建築的存續條件不是材料強度，是有沒有人在裡面

**Token 沒有反彈或蓄壓。** 有念生物離開 → 密度瞬間 1.0。這是物理常數，不是動態系統。

## 建造的真正意義

建築不是目的，是吸引人的手段。你蓋的不是房子，是「讓 NPC 願意來這裡住」的條件。

遊戲迴圈：探索 → 採集 → 建造 → **等人來** → NPC 遷入 → NPC 的存在維持聚念場 → 建築才能存續 → 聚落成形

## 與 [[聚落生成]] 的關係

聚落佈局 = NPC 集體建造決策的考古地層。不需要獨立的佈局演算法。

聚落的樣子就是「這群 NPC 在這塊地上生活了 N 年的結果」。用種子逆推：種子 + 地形約束 + 人口參數 → 反推聚落成長史 → 佈局。

詳見 [[NPC歷史生成]] 的逆推機制。

## 黑海拓荒

玩家衝進黑海建造 = 馴化混沌。建造 + 吸引 NPC → 密度降 → 環境從致命野地變成可居住邊疆 → 新聚落成形。

[[聚念場悖論]] 自動限制建造規模：建越多 → 聚念場越強 → 密度越低 → 資源越少 → 建材越難取得。
