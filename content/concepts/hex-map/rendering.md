# 渲染管線

> 單一管線原則、雙前端共用、禁止分叉、編輯器定位、三層地圖、玩家視距、Hex 眼圖 MVP 工單。

## 定案原則（2026-04）

- **同一張地圖、同一套渲染語意**：玩家端與編輯器端**不**各自維護第二套「合併格/林相邊界/幾何合成」規則
- **權威在後端**：與地圖可玩性、一致性、可重現性有關的運算（含格網狀態、揭露、契約釘、以及日後林區連通區、外輪廓等若由伺服器產出者）**以伺服器為準**；前端**僅顯示與操作**

## 禁止事項（避免分叉）

- **禁止**在「只有編輯器會用到」的前端路徑上，長期存放**僅前端計算**且與遊戲不一致的格網合成結果
- **禁止**為編輯器另開**未文檔化**的後端捷徑，且長期不併入正式契約；若屬暫時方案，須在 PR/註解標明**暫用與收斂期限**

## 雙前端

| 前端 | 現況 | 用途 |
|------|------|------|
| **編輯器** | `editor-leptos`（Leptos CSR + Canvas 2D，`/hex-editor/`）| 調教後台渲染與契約的製作介面 |
| **玩家端** | `web/` PWA | 接同一後端輸出；相機/HUD/權限可不同，底圖資料與幾何規則不分叉 |

### 編輯器定位（重要釐清）

- **專案主軸**是**探索/揭露/漸進生成**（世界隨遊玩逐步長出），見[[exploration|探索揭露]]
- 這與「開編輯器從零手繪整張地圖」的想像**方向不同**，並非否定編輯器存在
- **編輯器為何仍保留**：開發順序上編輯器在前，且前期需要編輯器介面與 `/api/hex/*` 調教後台渲染、契約與視覺，與「單一管線、後端權威」一致
- **未來實際遊戲**：仍以探索生成為準，**不以**「玩家或企劃在編輯器裡自繪全圖」作為常態產圖路徑；屆時編輯器能力可視為**留而不用**（除維運、除錯、特例工具需求外）

**實作線索**：Hex 格網 API 位於 `src/server/hex_editor.rs` 之 `/api/hex/*`；世界格與 PG/`data/hex/grid.json` 對齊。

## 三層地圖（2026-04-09/10 定案）

| 層級 | 範圍 | 用途 |
|------|------|------|
| **大地圖** | 全部已探索彩格 | 戰略總覽、回顧、路線規劃。選單進入，可縮放 |
| **視距地圖** | 玩家中心 5 格（VIEW_MAX_RING=5）| **主遊戲畫面**。固定比例尺、不縮放、可拖曳查看點選 |
| **瓦片地圖** | 技術層，玩家不感知 | 載入/渲染優化 |

- 視距地圖玩家字圓**錨定畫面中心**，世界繞玩家滑動
- 超出視距 5 格的彩格在視距地圖上**強制黑格**（遠距裁切，非存檔刪除）
- 已探索但超出視距的格子，只在大地圖可見
- 相機可拉多遠另由 UX 決定；黑格規則只依 d 與 R，不依縮放倍率改寫

## 玩家視距規則

**中心**：玩家當下所站之六角格（`q,r`）。

**距離 d**：該格與中心格之六角最短步數（cube/axial 距離）。

**設定**：VIEW_MAX_RING = R（正整數，例：5 或 10，可日後改）。

**顯示規則**：
- 若 **d <= R**：進入一般繪製（地形、河流、單位等）；若有「未揭露迷霧」在 d <= R 內再疊加
- 若 **d > R**：該格**一律畫成黑格**（不繪地形、不顯示「已開啟」的彩格內容）

**設計意圖**：
1. **體感**：遠處看不清——黑格是距離上的不可辨識，與「迷霧=從未走過」屬兩層語意
2. **效能**：主畫面只保證 d <= R 內的資料與繪製負載，圈外不必載入細節
3. **全圖另開**：玩家若要看全圖走單獨的「全地圖」入口，與主畫面分開；全圖可用縮略/低頻更新/靜態快照

## 視覺模式

**眼圖**（字圓模式）：畫面上是玩家字圓、NPC 字圓、格內物件，直接在 Hex 彩格上呈現。文字敘述不佔固定欄位，改為**觸發浮現**——踩進功能格時底部浮出一行簡述，點擊 NPC/物件展開互動面板。

**主介面願景**：全畫面即大地圖；玩家資訊（狀態、背包、設定、隊伍等）收在點擊玩家字圓後彈出的選單/面板。

## 玩家前端 Hex 眼圖 MVP（P0 工單）

**目標**：文字版 MUD 主畫面替換為 Hex 格網 canvas 眼圖，玩家可在 (0,0) 草原格上看到字圓並移動。

### MVP 範圍

**做**：
1. 登入後主畫面改為全螢幕 hex canvas
2. 渲染玩家所在格 + 視距 5 格內所有彩格（axial pointy-top，HEX_R=57px）
3. 玩家字圓錨定畫面中心，可拖曳平移
4. 點擊螢幕 -> 字圓朝目標方向直線移動 -> 撞不可走地形/實體停止
5. 移動速度 = `60 / move_cost` px/s
6. 底部狀態條（氣血/精神/內力/體力）半透明覆蓋
7. 同格 NPC 字圓顯示

**不做**：格內子座標、格內物件渲染、互動選單/插座系統、大地圖總覽、探索揭露（黑格生成）、敘事浮現文字、戰鬥/對話/交易

### 座標系統（玩家端）

- Axial 座標 (q, r)，pointy-top（與 editor-leptos 一致）
- 像素換算：`px_x = HEX_R * sqrt(3) * (q + r/2)`、`px_y = HEX_R * 3/2 * r`
- HEX_R = 57px，格寬 flat-to-flat = 57 * sqrt(3) ≈ 98px

### 相機

- 玩家字圓永遠在 canvas 中心
- 相機 offset = 玩家 hex 座標轉像素
- 其他格子像素位置 = 自身像素 - 相機 offset + canvas 中心
- 可拖曳平移（沿用現有 canvas.js 的 startDrag/moveDrag/endDrag），鬆手後不自動回彈

### 格子繪製

每個彩格：
1. 畫六角形填色（顏色來自 `Terrain::color()`，`src/hex/cell.rs` 已有）
2. 畫六角形邊框（1px，`#1a1a1a`）
3. 格內中心寫一個地形字（從 `terrain_display.rs` 候選字取，字色白或黑視背景亮度定）

視距外的格子不畫（canvas 背景色 `#0f1923` 即黑格效果）。

### 字圓繪製

- 玩家字圓：圓形，直徑 14px，填色 `#7ec8e3`，圓內寫 `display_char`（一個中文字）
- NPC 字圓：同直徑，填色 `#c4b8a8`
- 字圓畫在地形之上；同格多個字圓水平偏移排列

### 移動邏輯

1. 玩家點擊 canvas（非拖曳）-> 計算點擊位置相對於玩家的方向 -> 找出該方向最近的 hex 鄰居（6 方向取最接近的）
2. 前端發送 `{"Move": {"direction": "東北"}}` 等方向字串（`HexDir::label_zh()`）
3. 後端回傳 `RoomView`，前端用新 hex 座標重繪
4. 移動動畫：收到後端確認後字圓平滑滑動到新位置，動畫時長 = 格距 / actual_speed
5. 動畫期間不接受新的移動輸入；結束後重置相機讓玩家回到中心
6. 前端可做預判（已知地形 walkable=false 就不送請求）

### 新增後端 API

需新增 `GET /api/hex/view?player_id=xxx` 回傳視距內所有格資料：

```json
{
  "center": {"q": 0, "r": 0},
  "cells": [
    {"q": 0, "r": 0, "terrain": "grassland", "name": "草原", "color": "#4a7c59"},
    ...
  ],
  "entities": [
    {"id": "xxx", "q": 0, "r": 0, "display_char": "我", "kind": "player"},
    ...
  ]
}
```

cells 包含視距 5 格半徑內所有已存在的彩格。沒有格的座標 = 黑格，不列入。**這是本工單唯一需要改後端的地方。**

### 畫面佈局

```
+------------------------------+
|  [時鐘]              [背包]  |  <- 頂列，半透明浮層
|                              |
|        hex canvas            |  <- 全螢幕，佔滿視口
|      (玩家在中心)             |
|                              |
|  ░░░░░░░░░░░░░░░░░░░░░░░░░░ |  <- 底部狀態條，半透明
+------------------------------+
```

移除的 DOM：`#room-desc-panel`、`#narrative-panel`、`#room-name-wrap`、頂列五按鈕中除「背包」外全部。保留：`#auth-screen`、`#player-modal-overlay`、`#inventory-modal-overlay`。

### 驗收標準（手機 PWA）

1. 登入後 hex canvas 可見，(0,0) 草原格在中心
2. 玩家字圓在畫面中心顯示 `display_char`
3. 周圍彩格有顏色和地形字
4. 視距外（>5 格）為黑色背景
5. 點擊移動有速度差異（Road ~0.8s vs Grassland ~1.6s）
6. 點擊不可走方向不移動
7. 可拖曳平移
8. 頂列時鐘和背包按鈕可用
9. 底部狀態條可見半透明
10. 同格 NPC 字圓可見

### 技術提示

- `Terrain::color()` 已有每種地形的 hex 色碼
- `HexCoord` 有完整的鄰居、距離計算
- `HexGrid::cells_in_range(center, radius)` 可直接取視距內格子
- 前端 hex 像素計算參考 `editor-leptos/src/hex_grid.rs` 的 `hex_to_pixel`
- 現有 canvas.js 拖曳邏輯可複用
