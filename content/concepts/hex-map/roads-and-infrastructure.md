# 道路與活基礎設施

> 2026-04-12 設計暴脹產出，狀態：未收斂

## 核心物理

道路的安全性 = 有沒有人在走。

- 有人走 → [[聚念場]] 沿途壓制 [[Token]] 密度 → 安全
- 沒人走 → 密度瞬間 1.0 → [[富態化]] 全開 → 危險
- 石板大道沒人走 = 跟荒野一樣危險
- 泥巴路每天有商隊走 = 比人造大道安全

**路不是「修」出來的，是踩出來的。**

## 路網 = 世界心電圖

哪條路有人走，就知道哪兩個聚落之間有活的經濟關係。路死了 = 經濟關係斷了。

道路的存亡直接反映世界的社會經濟拓撲。不需要額外的「貿易路線」系統——路本身就是。

## 不存在「偏僻但安全」

偏僻 = 沒人 = 密度 1.0 = 持續性命威脅。安全和人口是同義詞。

獨居在這個世界裡是物理上不可能的——一個人的聚念場只能壓住身邊一小圈，睡覺時縮，出門時家裡就是 1.0。

## 與 [[聚落生成]] 的關係

道路網路不需要獨立生成——道路是 NPC 行走軌跡的累積結果。商人在兩個聚落之間走動 → 路出現。聚落死亡 → 沒人再走 → 路消失。

## 人是唯一基礎建設

建築存續需要人住、道路安全需要人走、資源採集需要人壓密度、聚落成長需要人搬入、內容深度靠 NPC 活著。

人不能囤積（有需求會走）、不能製造（出生成長遷徙）、是唯一能壓制 Token 密度的存在。
