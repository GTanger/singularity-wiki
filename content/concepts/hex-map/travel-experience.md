# 城際旅行體驗

> 兩城之間路線設計、三段互動骨架、事件槽機制、後台資料結構、驗收條件。
> 本頁為體驗設計參考，非 MUD 實作稿。

## 設計原則

- 玩家做「旅行決策」，不是「逐格操作」
- 文字主導、有空間感、低操作負擔
- 內部仍可用 Node/Route 計算，但前台不暴露 hop 與數值刷表語言
- 前台文案**禁止**出現 MMO 參數語言（降遭遇、耗時+2、buff/debuff）

## 固定三段互動骨架

每次城際移動固定輸出三段，不再逐節點報站：

| 階段 | 內容 | 玩家操作 |
|------|------|----------|
| **1. 出城抉擇** | 選路線性格 | 從 2~3 條路線中選 1 條 |
| **2. 途中兩段** | 兩個事件槽，世界回應玩家 | 每槽三選一（介入/旁觀/迴避） |
| **3. 入城落點** | 帶著結果進城 | 無操作，系統輸出結果 |

**玩家全程只做 1 次路線選擇 + 2 次事件反應。**

## 路線語意

路線只分語意，不寫成方向鍵流程：

| 路線 | 性格 | 典型事件 |
|------|------|----------|
| **官道線** | 穩定、消息多、變化小 | 公務與商務消息 |
| **河灣線** | 視野開闊、商旅多、突發中等 | 流動人群與臨時交易 |
| **舊礦線** | 收穫高、秩序差、事件尖銳 | 利益衝突與灰色場景 |

路線數與語意可依城際關係變化，以上為範例模板。

## 事件槽機制

每條路固定觸發兩段「場景事件槽」：

- **事件槽 A**（前半段遭遇）：早期事件池
- **事件槽 B**（後半段遭遇）：晚期事件池

每個事件槽提供三類反應（語意一致）：

| 反應 | 行為 | 效果傾向 |
|------|------|----------|
| **介入** | 主動處理眼前事件 | 高資訊/高風險 |
| **旁觀** | 低介入觀察 | 有限資訊 |
| **迴避** | 不捲入 | 行程穩定 |

## 入城落點

進城時系統**必輸出三項**：

1. **帶進城的狀態**（例如：被關注 / 帶著線索 / 沾上麻煩）
2. **解鎖的入口**（例如：工坊線、碼頭線、治安線）
3. **錯過的東西**（讓選擇有代價，不做完美路線）

入城結果**必影響至少 1 條城內可互動線**。

## 範例：霧港城 -> 赤石城

- 城際最短距離：8 格（符合 City<->City 8~14 建議，見[[settlements|聚落與野外]]）
- 選擇河灣線

### 事件槽 A

場景：河岸停泊點爭執（渡運工 vs 採買商隊）

- 介入：替一方說話，快速拿到赤石內部消息
- 旁觀：記下人名與口音，得到模糊傳聞
- 迴避：直接離開，保持行程乾淨

### 事件槽 B

場景：赤石外圍巡查加嚴，旅人逐一盤問

- 介入：主動配合，建立正面印象
- 旁觀：混在人群後方，觀察城門規矩
- 迴避：改走側邊入城點，避開正門視線

### 入城結果

- 帶入狀態：`守規旅人`（門哨態度中立偏正面）
- 解鎖入口：`赤石工坊區：舊帳簿傳聞`
- 代價：`錯過河灣夜市的短時機會`

## 後台資料結構

```json
{
  "route_id": "mistport_to_redstone",
  "route_styles": ["official_road", "river_bend", "old_mine"],
  "event_slots": [
    {
      "slot_id": "A",
      "phase": "early",
      "pool": ["dock_dispute", "bridge_block", "rain_shelter_crowd"]
    },
    {
      "slot_id": "B",
      "phase": "late",
      "pool": ["gate_inspection", "patrol_question", "outer_ring_detour"]
    }
  ],
  "responses": ["intervene", "observe", "avoid"],
  "city_entry_effects": [
    "unlock_workshop_thread",
    "unlock_harbor_thread",
    "raise_gate_attention",
    "lower_gate_attention"
  ]
}
```

用「敘事標記 + 城市入口影響」驅動結果，不用 MMO 數值語言。

## 驗收條件

- 玩家全程不需要連續方向鍵操作
- 玩家只做 1 次路線選擇 + 2 次事件反應
- 入城結果必影響至少 1 條城內可互動線
- 同一條路線重跑時，事件文本與落點可變（非固定劇本）
- 前台文案不出現 MMO 參數語言

若不符合，先改事件槽與輸出模板，不改美術。
