# 世界觀總覽

奇點世界的宇宙本體論。所有系統設計必須對齊此物理。

**風格基調**：純粹、客觀、深邃、莊嚴的混沌風格。不走修仙玄幻，不走賽博朋克；以宇宙觀測與物理降維的視角描述生命與修煉。

**一句話**：從有限框架延伸出無限可能。

**文化背景**：不貼單一標籤。修真、志怪、市井、江湖，都是這世界的一部分，不獨尊某一套語彙。世界用同一套規則對待所有人。

**體驗形式**：深度沉浸、重文字輕畫面。手機上的文字 MUD，以房間描述與事件 log 說故事。數值多半轉成敘述，只有少數（例如金錢「鎂」）可視化。

## 核心物理法則摘要

1. **Token** 是高維未知混沌能量，從宇宙暴脹的奇點噴湧而出，無處不在。僅其輻射就使無念物質富態化
2. **Token 烙印**：Token 混沌能量對萬物打下的定義。烙印即詞元根源，且沒有必定規律——火獸掉火是常數非必然
3. **同頻相斥**：有念生物高頻磁場與 Token 同質，天生屏障。「高頻」是物種屬性，非修煉結果
4. **止念**：壓制意識頻率至趨近零，方能汲取 Token 微波輻射
5. **降維**：混沌態 → 有序態 → 引入體內 → 激發生之奇點 → 星盤（N000 + 360 顆星）
6. **聚念場**：有念生物聚集排開 Token 輻射——城市安全、資源悖論、團戰抽薪，同一條規則
7. **Token 密度**：無人時恆為 1.0（滿值），有人在場則密度下降，人離開瞬間回 1.0
8. **剝名**：富態化物質/獸 → 剝離 Token 烙印 → 詞元結晶（可儲存交易） → 提出裸詞元（即用）
9. **附詞穩定**：有序詞元附著器物 → 阻隔游離輻射 → 使用穩定。穿戴者靠己念調頻
10. **富態化連續性**：物質沿原有生長邏輯繼續長，改變的是尺度與上限被抬高，限制框架同步富態化

## 設計約束

- **永序、守衡**：一切其來有自、因果相環，沒有無中生有的神蹟
- **豐饒不兌換安全**：愈沃野處往往愈兇
- **沃土風、非廢土**：請勿概括為廢土、末世、荒蕪。正確基調是沃土／富態／靜謐豐饒
- **玩家等於 NPC，NPC 等於玩家**：同一套實體與行為模型
- **觀測與坍縮**：視線未及時 NPC 處於多重可能並存；觀測才坍縮成發生的那條路
- **插頭與插座**：可互動對象有邏輯插座，玩家意圖是插頭，後端依匹配判定
- **五支柱全開放**：角色扮演、經營、模擬、建造、戰鬥——全時並行，沒有隱性階段
