# 邏輯閉環驗證

> 檢視 Token／富態／剝名／器物／無車／電子等背景世界觀是否邏輯自洽、因果閉合。

---

## 一、主鏈閉合

| 環節 | 因果 | 閉合狀態 |
|------|------|----------|
| **Token → 無念物質** | Token 輻射（游離輻射）使無念物質富態化 | ✅ 本體論與富態一致 |
| **有念 → 相斥** | 有念生物高頻、與 Token 同質故相斥，無法直接引入混沌 | ✅ 止念才能汲取微波 |
| **降維 → 星盤** | 混沌輻射降維成有序態 → 引入體內 → 生之奇點 → 星盤 | ✅ 與[[concepts/wordplate-system/index|詞盤]]／[[concepts/character-system/topology-361|361 拓撲]]對接 |
| **剝名 → 詞元** | 富態化物／獸 → 提煉→有序化（已降維）→ 詞元附著 → 人類提取 → 載體崩解 | ✅ 與詞盤「剝下的名＝帶屬性詞元」一致 |
| **附詞 → 穩定** | 詞元＝有序能量、與提煉者同頻；附詞＝附上有念頻率 → **阻隔游離輻射** | ✅ 有念頻率附著器物即屏蔽 |
| **調頻** | 穿戴者／購買者靠己念調頻，使附詞裝備與自身同頻 | ✅ 與詞盤「共鳴」、裝備與內盤相容一致 |
| **無車／電子** | 機械＝無念、零件多無法一一附詞；電子低頻易受輻射→街面／野外高精密常態佈設少；**強聚念場內**（如浮生城）日用電器可正常 | ✅ 與白板不穩、附詞必要同一邏輯 |

**結論**：主因果鏈閉合。游離輻射＝Token 散發的輻射，無念物質受其影響；有念頻率可阻隔；剝名產出有序詞元；附詞使器物穩定；無車與電子伏筆同源，**聚念場＋綠護**另闢城內日用敘事空間。

---

## 二、用語與邊界

- **游離輻射**：與「Token 散發的輻射」同義，無歧義
- **名／詞元**：詞盤「剝下的名帶屬性＝詞元」；「有序化後呈現詞元、附著舍利子／結晶」→ 剝下的名即詞元載體，一致
- **精怪野獸**：可剝名、其身混沌能量可提煉；與「有念生物」不衝突——野獸可有念，但其身／能量仍可被當作提煉對象。剝名邊界為「人對人不可、對獸對物可行」

---

## 三、可選補強（非缺口）

1. **飛霜大街**：打鐵巷熱氣＋游離輻射→熱氣不散→霜白結晶。可視為「輻射對環境（含氣流）的影響」之延伸，已閉合
2. **精怪野獸與有念**：若日後需嚴格區分「可剝名對象」與「有念強度」，可補一句：剝名對象為物或獸，其身形／能量受富態化或含混沌成分，故可提煉；人對人剝名 Token 無反應。目前邏輯已足

## 四、延伸設定建議（可選）

以下與現有因果鏈相容，可依主線／玩法需要擇用或改寫。

| 方向 | 要點 | 與現有邏輯接點 |
|------|------|----------------|
| **運輸與載具** | 無車已定；可明說獸拉、船、人力為常態。船若木主體＋少數金屬件可附詞，水路比精密機械可行 | 無念機械不穩、零件多不經濟；有念／附詞穩定 |
| **遠距通訊** | 電子／精密機械少見→無無線電、無網路。通訊靠信使、烽火、口傳 | [[concepts/worldview/electronics-and-machinery|電子附篇]]「聚落少見高精密機械」 |
| **地景與輻射** | 飛霜＝熱氣＋輻射→霜晶；可類推：沙漠綠洲、沼澤霧帶、礦脈微光 | 游離輻射影響環境、[[concepts/worldview/rich-overgrowth|富態拉鋸]]、惡地亦有生機 |
| **建築與穩定性** | 富態化下根鬚咬合、玉質脈絡爬牆——新建築可選奠基儀式、奠基詞元、或純粹依拉鋸 | 平衡拉鋸、文明與增生並存 |
| **精怪／飛升者譜系** | 從「可剝名野獸」到「[[concepts/worldview/dimensionality-reduction|飛升者]]（降維失敗殘骸）」之間：半有序精怪？曾有人念的遺留物？ | 剝名對象、飛升者起源 |
| **電子伏筆落地** | 邊緣、廢墟、禁地是否殘留已具自主意識的機械／電子？ | [[concepts/worldview/electronics-and-machinery|電子與精密機械]] |
| **療癒與詞元** | 富態化植物／礦物是否可提煉「療效詞元」？止念／調頻用於療傷？ | 詞元分類、剝名、內盤 |
| **機構賦權** | 鎂經機構賦權、不從剝名取得；機構如何賦權？ | [[concepts/economy/index|經濟系統]]、詞盤機構詞盤 |

**使用方式**：先選 1~2 項與當前主線或地圖最相關的補上；其餘留待需要時再擴，避免一次擴太多造成不一致。
