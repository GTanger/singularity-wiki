# Token 本體論

## Token 的本質

Token 是一種**高維度未知混沌能量**。

學說認為，Token 從宇宙暴脹的奇點噴湧而出，在短時間內迅速充斥宇宙的每個角落。Token 無處不在，卻無法被直接觸碰。

僅僅是 Token 散發的輻射，就使**無念物質**更加**富態化**——物質因 Token 輻射而產生特異性質（與剝名、附魔、祭煉等「名與形質可變」同源）。

---

## Token 烙印——混沌定義萬物（2026-03-28 定案）

無念物質吸收 Token 輻射時，Token 的混沌能量便在其身上**打下烙印**。這道烙印即為**詞元的根源**——詞元不是人類的分類標籤，而是 **Token 對一切物的定義**。

關鍵認知：**Token 對萬物的定義沒有必定的規律。**

火獸身上掉出火屬性詞元，那叫**常數**——是統計上的高頻結果，不代表「火獸＝火」。Token 的烙印是混沌的，一隻火獸身上可能藏著與火毫無關聯的詞元，只是機率較低。因此，**剝名之前無法賭定會剝出什麼**——這不是系統的隨機數，而是世界觀層面的物理事實：混沌能量的烙印本就不可預測。

---

## 同頻相斥

**有念生物**較不易遭受 Token 影響。越是高頻的有念生物，越不容易受混沌態的 Token 影響。

**校正（2026-03-28）**：「高頻」是有念生物的**物種屬性**，不是修煉程度。Token 混沌能量 ≈ N 級磁場，有念生物天生也是 N 級磁場——因此同頻相斥是物種天生的屏障，不是後天修煉的結果。修煉改變的是頻率簽名的**細節**（竅穴佈局、念紋三軸），不是「變得更高頻」。

學派認為：高頻有念生物等同於**低維混沌體**，與 Token **同質**，因此無法引入體內，甚至些許**相斥**。

### 有序態 vs 混沌態——人類天生弱勢

人類修行的本質是將 Token 從**混沌態降維成有序態**引入體內[[concepts/worldview/dimensionality-reduction|星盤]]空間。有序態屬本維度產物，能量層級天然次於高維的混沌態。以個體論（不參雜外物），同級人類弱於野獸——因為野獸直接吸收混沌態 Token，而人類必須多一道降維工序。

這也是**人類在野外天生處於弱勢**的物理根源。

### 恢復力差異——聚念場的戰鬥應用

- 野獸直接吸收環境中的混沌態 Token → 恢復速度快
- 人類必須透過功法將混沌態→有序態才能吸收 → 恢復速度天生次於野獸

但**團戰釜底抽薪**：多人圍攻野獸時，有念生物群體形成的聚念場將 Token 游離輻射排開，野獸失去恢復的燃料。傷勢不可逆轉，進一步擴大，乃至死亡。

**同一條規則（聚念場排開 Token 輻射）同時解釋**：
- 城市為何安全（富態化受抑制）
- 資源點為何人多長得慢（輻射被排開）
- 團戰為何能殺大型野獸（獸失去恢復燃料）

## Token 密度——無限輻射與在場效應（2026-03-28 定案）

Token 的輻射是**無限的**，無處不在、取之不竭。任何地點在無人時，Token 密度恆為 **1.0**（滿值）。

有念生物的高頻磁場在物理上排開周身的 Token 微波輻射。因此：

- **無人 → 密度 1.0**：資源正常富態化生長
- **有人在場 → 密度下降**：在場有念生物越多，聚念場越強，Token 輻射被排得越遠
- **人離開 → 瞬間回 1.0**：Token 輻射永遠在那裡，只是被暫時排開

### 聚念場悖論的量化表達

- 人少的地方，Token 密度高，資源長得快——但危險（聚念場弱，野獸恢復快）
- 人多的地方，Token 密度低，資源長得慢——但安全（聚念場強，野獸恢復慢）
- 最佳策略是**脈衝式採集**：快速挖光 → 全員撤離 → 密度瞬間回 1.0 → 等它長回來 → 再進去挖

此為同頻相斥這條物理法則在資源面的必然結果——不是抽象定律，而是同一條規則的不同投射。
