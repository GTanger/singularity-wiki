## 舊版核心設定：軟體工程的修仙皮

舊版最大的後設惡趣味：整個世界觀是軟體工程包了修仙的皮。

- **功法 = 程式語言**：Python 宗（華麗 AoE 但慢）、Rust 宗（精準不可擋）、C++ 流（威力最大但 Segfault = 走火入魔）、Go 流 = Google 正宗（併發蜂群攻擊）
- **戰鬥 = Debug**：反編譯對手法術、改 Target 參數、注入 Payload 奉還。殺人最好的方式是讓對手作業系統崩潰
- **天道 = Rust 後端驗證器**：只管真假不管死活。AI 幻覺生成的物品被天雷劈（Hallucination → Divine Retribution）
- **萬象儀 = 超級電腦**：雜念 = 記憶體洩漏、死循環 = 過時進程、鎖靈陣 = 防火牆
- **黑暗森林 = HTTP 404**：未渲染的混沌雜訊區
- **商隊 = 惰性寫入**：知識是貨物，青木鎮不知道台北存在直到有人拿著珍珠奶茶出現
- **科技巨頭 = 修仙門派**：Google = 古歌天庭、Apple = 靈果仙宗、Microsoft = 微塵道宮（藍魂劫 = BSOD）

## 可能值得重訪的概念

- **黑暗森林法則**：施法留下可偵測痕跡，強者反成靶子。與 Token 密度觀測系統有接合點
- **頻段執照**：控制特定能量頻段，無照修煉違法。與同頻相斥有接合點
- **道化（Dao Dissipation）**：經濟崩壞的美學昇華——不是餓死，是化為光點回歸天地。與 [[飛升與消融]] 有呼應
- **天譴驗證機制**：系統偵測無根之物立刻摧毀。現行 Rust 後端已有類似哲學但未遊戲化
